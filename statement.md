The Snake Water Gun Game is a Python based game where a user plays against the computer. The computer randomly picks Snake Water or Gun while the user enters their choice. The program checks both choices based on the game rules. Shows if the user wins loses or gets a draw.

## Scope of the Project

The project is about making a command line game using basic Python ideas. It shows how to use built in Python modules dictionaries user input selection conditional statements and basic game logic.

The project can be made better by adding features like:

* Multiple rounds

* Score tracking

* Option to play again

* Improved user interface

* Checking user input

## Target Users

This project is for:

* Python beginners who want to practice coding concepts.

* Students learning Python modules and conditional statements.

* People who want a command line game for fun.

## High-Level Features

* 🎮 User, vs Computer: The player plays against a computer.

* 🎲 Random Computer Choice: The computer randomly chooses Snake Water or Gun using the module.

* ⌨️ User Input: The user chooses their option using s w or g.

* 🏆 Winner Detection: The program finds the winner according to the game rules.

* 🤝 Draw Detection: If both players choose the option the game shows a draw.

* ⏳ Time Delay: A short pause is added using the time module.

* 🖥️ Screen Clearing: The os module is used to clear the terminal before the game starts.
